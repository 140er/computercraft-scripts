# Storage turtle with no map

The order computer is installed with `install role roomclient quick` and rebooted. The storage turtle has `room.cfg.a` and no `room.map`. It still hosts `roomsorter`. The order computer draws ORDER.

## Driving it with verify-computers

- Run `.cursor/skills/verify-computers/bin/verify-computers run no-map`.
- `docs/evidence/verify-computers/no-map-roomclient.txt` contains `ORDER`.
- `docs/evidence/verify-computers/no-map-turtle-up.txt` contains `starting roomsorter`.
